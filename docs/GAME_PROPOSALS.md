# 🎮 基金从业资格考试 · 26关金融模拟经营 HTML5 游戏策划案

针对**中国证券投资基金业协会最新考试大纲**（科目一《基金法律法规、职业道德与业务规范》**8章** + 科目二《证券投资基金基础知识》**18章** = **共26关卡**），我们将枯燥的法条与定量公式转化为可交互的**金融模拟经营机制**，同时彻底解决“像普通网页、需要上下滚动、不像真游戏”的痛点。

## 三大刚性设计铁律（所有方案通用）
1. **严格一屏完整显示（零滚动条）**：采用 `100vw × 100dvh` + `overflow: hidden` 锁死视口。电脑端呈 **16:9 居中游戏舞台**，手机端自适应为 **竖屏掌机布局**（适配刘海屏与底部安全区 `safe-area-inset`），绝不出现网页滚动条。
2. **纯粹“真游戏主页”与选关流**：摒弃仪表盘/学习网风格。首屏即**游戏标题画面（Title Screen）**：主视觉 Logo + 4 个干净菜单按钮（`开始游戏`、`章节选关`、`考纲图鉴`、`设置`）；点击“章节选关”进入一屏分页的 **26 关闯关地图**。
3. **纯静态 HTML5 + 一键公网部署**：零后端依赖（`localStorage` 自动存档 + 存档码导入导出），构建产出标准静态 HTML 游戏，支持通过 **GitHub Pages** 直接打通自动发布链路，手机/电脑点开链接即玩。

## 一、 5 种金融模拟经营游戏策划方案

### 🏢 方案 A：《公募帝国：26层摩天楼》（模拟建造 + 部门经营 · 综合最推荐）
- **对标经典**：《开罗财阀都市》/《大厦管理者 Project Highrise》
- **核心玩法**：从 5000 万发起式资金筹备处起步，每攻克 1 章考纲向上加盖 1 层专业部门（1~8F 合规风控基座对应科目一，9~26F 投研估值销售中枢对应科目二），建成 26 层千亿公募帝国大厦。
- **单关循环**：新楼层挂牌（30秒考纲机制卡）→ 季度试运营（点击楼层小人头顶业务气泡，处理合规审单/加息调久期/巨额赎回等经营工单，管理 AUM、NAV、合规值、管理费）→ 季度末“协会飞检 Boss 战”（高频真题终审）→ 点亮楼层评星 `★★★`。

### 👑 方案 B：《抉择王座：基金掌门人》（卡牌滑动 + 四维平衡生存 · 手机单手最佳）
- **对标经典**：《王权 Reigns》金融执业版
- **核心玩法**：扮演基金公司总经理兼基金经理，顶部维持【管理规模】【净值收益】【持有人信任】【监管合规】四维平衡（任一归零触发清盘/吊销牌照）。
- **单关循环**：投研总监、托管行、渠道经理、激进散户、稽查员轮流递上考纲情景事件卡，玩家左滑/右滑做执业拍板，落牌即解锁【法条/公式护身符】，撑过 12 个执业月并通过年度考核即过关。

### 🕵️ 方案 C：《陆家嘴操盘台：首席风控与基金经理》（第一视角桌面微操 · 计算与细节最强）
- **对标经典**：《请出示证件 Papers, Please》+ 实盘量化调参台
- **核心玩法**：沉浸式双联屏金融工位。
  - **科目一（1~8关）**：桌面递入《宣传海报》《基金合同》《兼职申请》，玩家对照速查红宝书，直接在违规字眼（如“承诺保本”“募集期超3个月”）上点选并盖下【合规放行 / 违规驳回】大印。
  - **科目二（9~26关）**：切换为动态量化沙盘，亲手拖动资产权重画有效前沿、拨动久期滑块抵御加息、勾选可列支费用计算当日份额净值送交托管行复核。

### 🎲 方案 D：《大资管时代：26季牛熊商战》（环形棋盘经营 + 考纲技能卡构筑）
- **对标经典**：《大富翁》+《文明》科技树
- **核心玩法**：一屏 16 格环形金融市场棋盘（募集格、A股格、债市格、衍生品对冲格、托管结算格、协会抽查格），与 AI 竞争机构在牛熊周期中比拼 AUM，打出每章解锁的“考纲策略卡”化解黑天鹅与监管抽查。

### ☕ 方案 E：《基民买手店：财富处方笺》（顾客接待 + 组合配方经营）
- **对标经典**：《老爹汉堡店》/《深夜酒馆》财富管理版
- **核心玩法**：经营一家街角合规财富买手店，接待不同风险偏好与资金期限的投资人，在营业时间内完成【KYC风险测评 → 挑选匹配基金品类 → 核算申赎费率与分红税收 → 合规风险揭示】全套处方交付，升级店铺货架。
