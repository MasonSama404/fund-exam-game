# 🏛️ 公募帝国：26层摩天楼 (Fund Empire: 26F)

面向**中国证券投资基金业协会最新考试大纲**打造的**一屏自适应 HTML5 金融模拟经营闯关游戏**。

## ✨ 核心特性
- **26 层公募大厦 = 26 章最新考纲**：
  - **第一幕（1F–8F）**：科目一《基金法律法规、职业道德与业务规范》全部 8 章
  - **第二幕（9F–26F）**：科目二《证券投资基金基础知识》全部 18 章
- **严格 `100dvh` 一屏无滚动双端适配**：
  - 电脑端（横屏 16:9 居中主舞台）+ 手机端（竖屏掌机分舱布局，刘海屏安全区适配），全程零滚动条。
- **纯正独立游戏主页与核心循环**：
  - 极简游戏主菜单 → 26 层双幕选关蓝图 → 新部门挂牌（4条核心考纲铁律） → 季度业务工单模拟（AUM规模 / 单位净值 / 合规护盾实时联动 + 稳健/冲刺经营方针 + 投研内参排错） → 协会飞检真题终审 → 金牛三星评定与错题自动收录销号。

## 🛠️ 本地构建与运行
```bash
python3 scripts/build.py
# 直接用浏览器打开 index.html 或启动本地静态服务：
python3 -m http.server 8080
```

## 🚀 自动部署链路
仓库内置 `.github/workflows/deploy.yml`，推送到 `main` 分支即自动构建并发布至 **GitHub Pages**。
